## 🚀 Featured Projects

### [Switchable-Barrier Thermal Runaway Model ↗](https://github.com/adityameenak/switchable-barrier-runaway)
Finite-volume simulation of thermal runaway spreading cell-to-cell through a lithium-ion battery stack, comparing no barrier, a conductor, an insulator, and a temperature-switchable barrier. Includes a design map for the switch, a switch-temperature sweep, and a LaTeX technical report.

**Only the switchable barrier wins both ways:** it contains runaway to **1 of 5 cells** while keeping normal operation at **38 °C** (vs. 64.5 °C for the insulator).

**361-run design map · 18 validation tests · energy conserved to 10⁻¹²**
